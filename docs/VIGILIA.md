# Azphelumbra · Vigília

The 0.10.0-beta.1 interface keeps the current session and module switches
beside the main page. Navigation icons have tooltips and accessible names.
Gatherables, hidden cubes, and overlay settings remain available beside them.
Switch between Portuguese and US English in **Settings**.

## Impacto combat panel

The floating panel appears in recognized instances when enabled. Bars show
each identified player's DPS relative to the highest observed DPS. Official
class silhouettes receive the approved design palette; the palette does not
claim to reproduce every in-game color exactly. Assassin uses green.

Click a player to see damage and participation. **Details +** expands all
rows. The arrow collapses the ranking to your DPS. The pin locks movement;
unlock it and drag the title to move the panel. Its controls remain clickable.
Use the quick menu to hide the panel without stopping measurement.

Unassigned damage remains separate. Party DPS includes that observed damage,
but an unidentified source never receives an invented individual DPS.
Saved history does not replace the live panel when selected in the main app.
**Combat settings** contains opacity, position recovery, and capture status.

## Fita event strip

The collapsed strip shows one upcoming occurrence, its icon, local start time,
and countdown. Expand with the arrow for the day's schedule. The calendar
button chooses which event to follow. The same choice applies in **Events**.
Drag the event title to move the strip. No timezone conversion rules changed.

## Other overlays

The emblem opens module switches and the app. Sonar retains its audio
detector and shows a segmented intensity meter. The favorite-pet panel uses
original portraits and the existing collection. Map controls share Atlas
layers with both game maps. Closing a panel does not stop another module.

All HUD windows continue to follow game focus and recognized menus. This
release adds no continuous animation timer to combat bars or map controls.
Configured map drawing and capture rates remain unchanged.

## Upgrading

Azphelumbra is the new display name for Strigoi Aether Map. The executable,
registry keys, and data folder keep their earlier identifiers so an upgrade
preserves preferences, visits, history, and pet collections. The installer
updates the shortcut's visible name. GPLv3 and third-party notices still apply.

The game parser, map coordinates, event schedules, and audio reference are
unchanged by this interface release. Controlled UI checks do not establish
live-game FPS or complete regional protocol coverage.
