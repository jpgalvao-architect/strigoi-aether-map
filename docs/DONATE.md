# Donate — apoio ao criador e fontes institucionais

Revisão em 2026-10-12, versão 0.7.1. A página oferece apoio pessoal ao criador
e doações às instituições, com destinatários indicados em cada opção.
O aplicativo não processa pagamentos nem coleta dados financeiros.

## Apoio ao criador

O botão **Apoiar o criador · Mercado Pago** abre
[o link fornecido pelo criador](https://link.mercadopago.com.br/thothworlds).
Esse apoio é pessoal, distinto das doações às instituições. O endereço foi
incluído conforme fornecido; a página não pôde ser carregada pelo verificador
web. Não foi realizado pagamento nem confirmado o destinatário do checkout.

## Instituições

As doações seguem diretamente para os canais de cada instituição. Não foram
incluídas organizações identificadas como evangélicas. As duas selecionadas
se apresentam como associações civis dedicadas à comunidade surda.

- **ASSJP — Associação dos Surdos de São José dos Pinhais:** a página
  [Seja Apoiador](https://assjp.org.br/junte-nos/seja-apoiador/) apresenta
  formas de doação e atuação social, cultural, educativa e esportiva.
- **ASC — Associação dos Surdos de Contagem:** o
  [site oficial](https://www.ascontagem.org.br/) descreve defesa de direitos,
  acessibilidade, inclusão e mantém a seção Doações. O botão abre a página
  inicial, onde o usuário escolhe Doações. O conteúdo foi conferido pelo
  índice de busca do próprio domínio; acesso direto pelo verificador recebeu
  HTTP 406. Não foi realizada uma transação nem auditoria financeira.

Dados bancários e chaves PIX não são replicados no app. O usuário consulta
os dados atuais diretamente no canal escolhido. Os nomes identificam os
destinos externos; não implicam parceria formal com o projeto.
