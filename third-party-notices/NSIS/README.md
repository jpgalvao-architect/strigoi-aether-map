# NSIS 3.12

O instalador e o desinstalador foram compilados com NSIS Unicode 3.12.
O núcleo, Modern UI e plugins conservam sua licença zlib/libpng; o módulo
LZMA conserva CPL 1.0 com a exceção de ligação indicada pelo fornecedor.
`COPYING.txt` é cópia integral e inalterada do aviso da instalação do compilador.

Isso não relicencia o código próprio, dados ou assets do aplicativo.
O script `.nsi` e o preparador próprio usam GPLv3, conforme LICENSE-NOTICE.md.
Os componentes NSIS não foram modificados.
