3. How the application works

Markers, the event panel and alerts appear in external overlay windows. Map recognition analyzes the screen image, and Sonar receives audio from the selected application through Windows features.

Strigoi does not inject code into the game's DLLs, modify its files or read its memory. It does not perform game actions automatically. This technical description does not represent authorization from the AION 2 developer or operator.

The experimental Combat module passively reads traffic received through the game's connection using Npcap when enabled by the user. It shows observed damage; results may be partial and regional compatibility needs validation. It does not send or modify game packets. Npcap is obtained from its publisher, with its own license and installation wizard.

4. Data and accessibility features

Preferences and exploration records are stored on this computer. Image and audio analysis takes place locally. Sonar does not use the microphone or record analyzed audio.

Combat history is also local. Raw packets are not recorded or uploaded. Observed names and results may appear in history and in text voluntarily copied by the user. Npcap download accesses the publisher's site following the choice in the installation flow.

Sonar was developed as a hearing accessibility feature, converting a sound cue into a visual alert. Capture features require activation by the user. Remote schedule updates and external links, when used, access the selected services and are subject to those services' policies.
